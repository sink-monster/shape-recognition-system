# 🎨 智能形状与物体识别系统

一个基于 Python 的智能识别系统，支持**二维几何形状识别**和**物体识别**两种模式。

---

## 🚀 快速开始

### 运行程序
```bash
python deep_recognition.py
```

### 使用步骤
1. **加载图片**：点击"加载图片"按钮，选择要识别的图片
2. **选择模式**：
   - 🔷 **二维形状识别**：识别圆形、矩形、三角形等几何形状，并识别颜色
   - 📦 **物体识别**：使用 YOLOv8 识别 80+ 种日常物体
3. **开始识别**：点击"🚀 开始识别"按钮
4. **查看结果**：图片上会标注识别结果，底部面板显示详细信息

---

## ✨ 功能特点

### 🔷 二维形状识别
- ✅ 识别圆形、正方形、矩形、三角形、五边形、六边形等
- ✅ 自动识别形状颜色（红色、蓝色、绿色、黄色等）
- ✅ 显示形状面积、顶点数、中心点坐标

### 📦 物体识别（YOLOv8）
- ✅ 使用最新 YOLOv8 深度学习模型
- ✅ 支持 80+ 物体类别识别
- ✅ 可选择模型大小（Nano/Small/Medium/Large）
- ✅ 可调置信度阈值和 IOU 阈值

## ⚙️ 参数说明

### 形状识别参数
- **最小检测面积**：过滤小于此面积的形状（默认 100 px²）
- **多边形近似系数**：值越大，近似越粗糙（默认 0.04）

### 物体识别参数
- **模型大小**：Nano（最快）→ Small（推荐）→ Medium → Large（最准）
- **置信度阈值**：过滤低于此置信度的检测结果（默认 30%）
- **IOU 阈值**：非极大值抑制阈值（默认 45%）
- **TTA**：测试时间增强，提高识别精度（会变慢）
